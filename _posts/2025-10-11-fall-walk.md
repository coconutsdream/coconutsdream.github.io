autumn vibes.

for the photos, i mostly used this [kodachrome64](https://www.youtube.com/watch?v=TjaBbR50ZAs&t=103s) simulation. i find myself using this recepie a lot lately. the photos are indeed very pleasing to look at. for two photos, i also used the bright nostalgic setting.

**krome64**\
simulation: classic chrome\
grain effect: off\
colour chrome effect: off\
colour chrome blue: off\
white balance: wb shade or wb auto\
wb shift: 0 red, 0 blue\
dynamic range: dr200\
highlights: -0.5\
shadows: -0.5\
color: +1\
sharpness: +1\
iso noise reduction: -1\
clarity: 0

**bright nostalgic**\
simulation: classic chrome\
grain effect: strong, large\
colour chrome effect: strong\
colour chrome blue: strong\
white balance: auto\
wb shift: 0 red, 0 blue\
dynamic range: dr200\
highlights: -2\
shadows: -2\
color: +4\
sharpness: -2\
iso noise reduction: -4\
clarity: 0
